## 1. 一句话定位

Block-7 是一个 AI 驱动的小型社会模拟器，灵感来自 Stanford / Google Research 论文 *Generative Agents: Interactive Simulacra of Human Behavior*（Park et al., 2023, arXiv:2304.03442）。

8–12 个由大语言模型驱动的 NPC 在一个虚构世界里**自主**生活、互动、产生剧情；玩家通过 Godot 4 客户端观察并最终能介入。目标是看到"涌现行为"——开发者没编排、但角色之间因为各自动机互动出来的故事。

## 3. 技术架构（直接约束世界观可行性的部分）

| 维度 | 关键参数 | 对世界观的约束 |
|---|---|---|
| LLM 模型 | DeepSeek V4-Pro（核心 agent）+ V4-Flash（背景/对话） | 厂商内容审核：避免极端暴力 / 性内容 / 明显反政府主题 |
| 上下文窗口 | 1M tokens 标配 | 单 agent 人设可写到 ~2000 字 |
| Prompt 缓存 | 4 层结构，前 3 层必须**字节稳定**才能 91%+ 命中 | 世界观一旦敲定就尽量不改；改一字命中率会掉 |
| Agent 数量 | MVP 8–12 个（可先 5 个起步） | 上限 12，每多一个都增加 prompt 体积 |
| 场所数量 | 3–4 个 | 不超过 4，每个要有清晰功能 |
| 输出语言 | 中文 | 角色姓名、对白、心理活动都用简体中文 |
| 检索方式 | SQLite 关键词 LIKE + 时间衰减（**不用向量检索**） | 角色姓名、地点名、关键事件主题词必须是 ≥2 字的独特中文词 |
| 时间系统 | 现实 1 秒 = 虚拟 1 分钟 | 现实玩 24 分钟 ≈ 游戏内 1 天；故事节奏要适配"几个游戏日"内能看到推进 |

## 4. 核心架构亮点（你不需要懂细节）

- **快动作慢思考**：Agent 身体按 Action Queue（行动队列）一步步执行；脑子（LLM）在背景异步规划下一批动作。这意味着角色"有思考的时间"，画面不会卡顿。
- **三类记忆**：observation（观察）、reflection（反思）、plan（计划）。每条记忆有 1–10 的重要性分数。
- **同场所感知**：Agent A 在某地做的事，会被同地点的其他 agent "看到"并写入他们的 memory。这是涌现互动的物理基础。
- **每日反思**：每个游戏日结束时 agent 会回顾当日记忆、提炼出高层次理解，影响第二天的规划。
