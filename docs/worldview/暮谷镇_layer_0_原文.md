【世界观:暮谷镇】

暮谷镇坐落于一片异世界的边境地带——寒带的雪原与热带的湿谷在此交界,形成一片小型盆地。这片地脉异常,涌现"魔物":会感染村民并将其转化的诡异生物。一百多年前,拓境者协会(一个跨界的半官方组织,综合了研究院、行政机构与探险家公会三种职能)开放了这片"异常区域"的拓荒权,鼓励有志者来此定居、研究、谋生。村民来自四面八方:研究者、移民、避难者、跑商者、退役军人、二代定居者。村子完全自给自足——有铁匠、医者、炼金术师、农民、捕魔队员、商人、酒馆主。协会扮演的是远方的合作伙伴:派驻村员、买研究成果、发法令、危急时支援——但远水救不了近火。村中有四个主要场所:老松广场(中央枢纽)、北霜工坊(寒带,提炼解药矿物)、暖谷农场(热带,种草药)、寂塔遗迹(村东,神秘古塔)。

【时间与节奏】

暮谷镇的一天从黎明开始。晒太阳的老人最早到老松广场。上午是劳作高峰,中午村民聚到苏拂的酒馆吃饭,下午各自回岗位,黄昏酒馆再次热闹,夜晚大部分人入眠——但失眠者总是有的。"小魔潮"是村里的常态:不定时发生,每次感染 1–3 个村民,村里能处理。但古老记载暗示,每隔几十年会有一次"大魔潮"——能感染全村,触发周期性的"重置"。预言的日子正在临近,只是大多数人不当回事。每三日一次集市,每月有一两次协会的法令更新,每年有一次"霜髓节"(冬至前后,村民共同上山取霜髓矿)。

【社会结构与风俗】

村子内部完全自治,村长由议事会推举,目前的村长是沈砚。村民之间没有严格阶层,但有微妙的资历差——老一代(在村几十年)、中坚一代(扎根十几年)、新移民(几年内来的)。外来者大致分两类:协会派驻的研究员或驻村员(享有制度地位但社交距离远),以及自愿来的客居者(身份多样,接纳程度看个人)。文化背景多元——主体为东亚血统,也有来自东方海上邦国的退役者、来自西方的客居研究员等,但村里的共同语言是中文,日常生活相互融合。村里有几条不成文的规矩:不要在午夜独自停留老松广场的歪脖子松树下;不要深入北霜工坊后院的冰窟;听到寂塔传来低沉声响要立刻撤离。这些规矩没人记得为什么有,但所有人都遵守。被感染过又被治愈的村民被称为"治愈者",社会上不歧视他们,但他们之间有一种沉默的共识——某种"我们都做过那个梦"的微妙连结,从不在公共场合提起。

【经济与生计】

村庄经济以"解药关键资源"为核心:北霜工坊出产的霜髓矿、暖谷农场培育的草药、各类炼金成品——这些既供村内使用,也部分上交协会换取现金或物资。其余生计为常规农工(铁匠、织布、种菜、饲养)。马九这样的跑商把村内特产送到外界,带回协会订购的稀缺品。村里基本没有赤贫,但稀缺资源(优质矿石、特殊草药、罕见解药)永远不够分,谁能优先用,常引起小纠纷。中央集市每三日一次,本村加邻村的小商贩都会来。

【当前氛围与潜在催化剂】

最近几个月,村里陆续有迹象让敏感者不安:几个被治愈过的村民开始做"相似的梦";老松树似乎在缓慢长高;协会发来的"地脉数据"屡次被退回要求重新测量;白嬤每年那个收落叶的陶罐今年快满了。预言中的"大魔潮"可能就要来了——但大多数村民对此半信半疑,日子照过。空气里有一种说不清的紧绷,但表面上一切如常。某些角色心里都藏着自己的疑虑、私心和秘密,只是还没到摊牌的时候。
