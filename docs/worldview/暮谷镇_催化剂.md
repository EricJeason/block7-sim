# 潜在催化剂:大魔潮临近

## 是什么

预言中的"大魔潮"——按古老记载,每隔几十年发生一次的全村级感染事件。这次大魔潮可能在游戏开始后的几个游戏日内被触发。它的物理机制是地脉"涨潮"达到峰值,被封印或潜伏的魔之力外溢,大量魔物涌出寂塔遗迹方向。被感染的村民将经历"初期感染→中期魔物→晚期魔物"的转化过程,且转化后保留对前任身份重要的人/地的偏好。

如果全村被感染,触发"循环重置"——所有被感染者恢复村民身份,但保留模糊的梦境碎片。

## 触发条件

不是必然发生。它是否真的来,取决于多条线索的累积:

- 治愈者梦境同步达到临界(目前已有三人做相似的梦,第四人出现时是阈值)
- 白嬤的陶罐填满(已经接近)
- 老松广场的歪脖子松树突破某个临界高度
- 地脉数据连续偏离(协会的修订记录已经异常)
- 寂塔遗迹某块特定的石头被翻动(艾琳/早纪可能触发)
- 高频感染者(阿杏)的梦完全清晰化

如果这些信号在几日内累积超过 3–4 个,大魔潮就会在某个夜里突然降临——通常是子时,从寂塔遗迹方向开始。
