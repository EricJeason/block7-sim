## 0. 给 Claude Design 的一句话定义

你在做的是 **PC 端生成式 NPC 社会模拟器** 的 UI 视觉稿。
项目代号 **Block-7 · 暮谷镇**。
12 个 LLM 驱动的 NPC + 4 个场所 + 玩家扮演其中一人,通过靠近、读心、对话观察这个小镇的涌现叙事。

**最终载体**:Godot 4(桌面端,1280×720 起步,支持 1920×1080)
**当前设计载体**:React + Babel CDN(平板原型,用来快速验证视觉,最终 port 回 Godot)
**两者共用视觉规范**——这份文档就是规范源头。

**参考坐标系**(精确到维度,不是泛参考):
- **Stardew Valley** — 像素美术的完成度标准 + 木质 UI 控件的温暖感
- **To the Moon** — 叙事氛围 + 屏幕"绝大多数时间是世界本身,UI 只在需要时浮现"
- **Disco Elysium** — modal 全屏沉浸式信息展示 + 角色档案的"内心可被打开"感

**项目最特别的地方**(必须在 UI 上传达):这是 **悬疑生活流 + 循环 horror**,不是明亮可爱的种田游戏。表面平静的小镇,水面下藏着治愈者、寂塔遗迹、被擦掉的记载、临近的大魔潮。UI 要有"宁静中暗伏紧绷"的体感。

## 1. 世界观速通(给设计师建立直觉)

### 暮谷镇 · 一个异世界边境小镇

- 地脉异常涌现"魔物",一百多年前**拓境者协会**开放拓荒
- 村民来自四面八方,自给自足:铁匠、医者、炼金术师、农民、捕魔队员、商人、酒馆主
- "小魔潮"是常态,每次感染 1-3 人,村里能处理
- 古老记载暗示每隔几十年有一次"**大魔潮**"——能感染全村,触发"循环重置"
- 预言的日子正在临近

### 核心主题

**身份的连续性、记忆的可信度。** 被治愈过的村民被称为 "治愈者",社会上不歧视,但他们之间有一种沉默的共识——某种 "我们都做过那个梦" 的微妙连结,从不在公共场合提起。

## 2. 已锁定的视觉规范(不要推翻,可微调)

### 2.1 配色

| 用途 | Hex | 说明 |
|---|---|---|
| UI 主底(羊皮纸暖底)| `#E8DCC4` | 所有 panel / 容器的主色 |
| UI 边框 / 烧字(旧橡木墨)| `#6B5840` | 边框、分隔线、深色文字 |
| 强调(封蜡红)| `#8B4513` | 警示、关键按钮、重要 tag |
| Modal 遮罩 | `rgba(26, 20, 16, 0.78)` | 全屏 modal 背后的暗化层(隐约保留场景剪影)|

场景配色不在 UI 规范内(每个场所有自己的主色,见 §1)。**UI chrome 是统一的,场景视觉是各自的**——这个边界请保持。

### 2.2 字体三组

| 用途 | 拉丁字体 | 中文 fallback |
|---|---|---|
| UI 主文字、标题、NPC 名 | Cormorant Garamond | Noto Serif SC(思源宋体)|
| 心声、反思、日记(S4)| Caveat | Ma Shan Zheng(马善政书)|
| 系统信息、时间、cost、debug | IBM Plex Mono | Noto Sans SC(思源黑体)|

**只用这三组,不要再加。** 两种衬线 / 两种手写体并存会让界面乱掉。

### 2.3 Modal 分层规则

- **重量沉浸**(S4 读心 / S11 对话 / S5 关系网)→ 全屏淡入到 78% 黑,背景留剪影,完全打断走路
- **轻量信息**(Q 场所概览 / T 大事件日志)→ 半屏卡片或侧栏,不打断走路
- **系统功能**(Esc / S12 暂停菜单)→ 侧栏滑入

### 2.4 NPC 视觉路线

- **像素 sprite**(64×96 像素,匹配 A 项目现有 Godot 实装)
- **每个 NPC 需要的素材**:walk_n / walk_s / walk_e / walk_w + idle(共 5 套朝向)
- **当前唯一完成的**:艾琳(agent_04)有金发蓝裙真实立绘,其他 11 个目前是色块占位
- **风格**:统一像素风,贴近 Stardew Valley 的清晰度,但配色和氛围要符合暮谷镇(不要太明亮可爱)

### 2.5 NPC 站位:锚点制

不要 4×3 网格!每个场所背景上预设 **5-10 个语义锚点**,LLM 生成的 action 映射到对应锚点。

示例(老松广场):
```
井边        (340, 520)
酒馆门口    (180, 600)
老松下      (640, 450)
议事厅前    (820, 380)
广场中央    (500, 540)
角落长椅    (1050, 620)
```

请在 4 张场景背景图上用红点 + 标签标出推荐锚点位置。Eric 会根据 NPC 行为微调。

## 3. S3 主屏 layout(本轮设计核心)

### 3.1 极简 HUD,只留三件

```
┌──────────────────────────────────────────────────┐
│              ┌──────────────┐                    │
│              │ ☀ DAY 3 · 15:52 │ ← 顶部中央木板时钟│
│              └──────────────┘                    │
│                                                  │
│                                                  │
│                                                  │
│         [世界视图:单场所大背景]                  │
│         [玩家 sprite(WASD 移动)]                │
│         [NPC sprites(锚点站位)]                 │
│                                                  │
│                                                  │
│   老松广场                                       │
│   4 人在此                              E 互动   │
│                                          Esc 菜单 │
└──────────────────────────────────────────────────┘
```

**没有常驻 Inspector / MemoryPanel / 反思计数器 / cost panel**。这些信息要么按需呼出(F/Q/R/T/M),要么只在 debug 模式可见。

**左下小字**(场所名 + 在场人数):Cormorant Garamond,18px,墨色 `#6B5840`,半透明 0.85
**右下小字**(键位提示):Plex Mono,12px,墨色 0.6 透明度

### 3.2 顶部中央木板时钟(详细规格)

- **尺寸**:240×52 像素
- **背景**:浅木 `#D4B896` 主色 + 深木 `#8B6F47` 边,轻微做旧、烙印质感
- **挂法**:从屏幕顶部垂下嵌入感(top: -4px,看起来"嵌进"屏幕上沿)
- **图标**(左侧 16px):
  - 6:00-11:00 → ☀ 朝阳
  - 11:00-17:00 → ☀ 烈日
  - 17:00-20:00 → 🌅 黄昏
  - 20:00-6:00 → 🌙 月亮
- **文字**:`DAY 3 · 15:52`
  - 字体:Cormorant Garamond
  - 字号:20px
  - 颜色:`#3D2F1F`(深咖)
  - 全英文 + 24 小时制(**不要中文**,要的是国外轻松休闲游戏感)

**参考**:Stardew Valley 右上角小日历的木板感,但更窄、更横、更克制。

### 3.3 走近 NPC 的 hover 信息

- 玩家距离 NPC < 100px 时,**NPC 头顶**浮现:
  - 极淡灰色斜体文字一行
  - 字体:Cormorant Garamond italic 或 Noto Serif SC italic
  - 字号:14px
  - 颜色:`rgba(60, 50, 40, 0.7)`
  - 内容:NPC 当前 action 的简短描述(例:"在井边打水"、"看着远处的山")
- 走开消失,**不常驻**
- **没有 💭 思考灯泡常驻**——上帝视角语言,跟扮演体验冲突

### 3.4 E 键交互:头顶小气泡菜单

按 E 时最近的 NPC 头顶弹出气泡菜单,选项:

```
    林秋
  ┌─────────┐
  │ 打招呼  │
  │ 读心 *  │
  │ 离开    │
  └─────────┘
       ▽
```

- 气泡风格:羊皮纸底 + 旧橡木墨边,圆角 4px
- 字体:Cormorant Garamond 16px
- "读心" 后面带 `*` 表示有限次/有代价(具体机制 v0.4 再定,UI 上要为这个 affordance 留位置)
- 按方向键或鼠标 hover 选中,Enter 或点击确认

## 5. 世界结构 primitive(给视觉设计参考,不需要你设计)

设计师不用管这块,只需要知道:

- 玩家有 `(x, y)` 坐标(场所内的局部坐标系)
- 每个场所是独立的 Scene,有自己的 width / height / exits[]
- 走到 exit 区域触发场景切换(**不是**按数字键)
- 1-4 数字键保留为开发期 debug 传送
- 这套结构未来要扩展成"一张连续大地图 + 多个室内箱庭",所以**场景之间的 exit 在视觉上要明显**(门、桥、路、台阶),让玩家凭直觉走到那里就知道"我可以离开这个场景"

## 6. 反思机制(后台跑,UI 不常驻)

Stanford 论文那个跨日反思机制在 A 项目后端已实装且跑得很好。UI 上的处理:

- **不要常驻反思计数器**(A 截图里的紫色"🌒 反思: N 条 / Day X" 撤掉)
- 玩家通过 **F → S4 "读自己的心"** 看到自己角色的反思
- **不直接看其他 NPC 的反思**——其他 NPC 的反思要靠 S4 的 "读别人心" 功能(v0.4 实装,有限次/有代价)
- S4 的反思呈现:建议用"翻开内心笔记本"的全屏 modal,Caveat 字体手写感,一条一条像写在纸上浮现

## 7. 留给 Claude Design 自由发挥的两个点

这两个不强制定方案,但希望你给出 1-2 个具体提案,让 Eric 选:

### 7.1 治愈者的视觉暗示

12 个 NPC 里有几个是被治愈过的(林秋、阿杏)。社会上不歧视,他们之间也不在公开场合提起。但 UI 上能不能有一个**克制的、玩家可能发现也可能错过的**视觉信号?

例如(仅供启发,你可以提别的):
- 治愈者 NPC 的名字标牌边缘有极淡的紫色光晕
- 治愈者的对话气泡边角有一道几乎看不见的描边
- 夜晚场景中,治愈者头顶偶尔飘过一缕"梦境碎片"粒子(0.5 秒,极淡)

**关键约束**:不能直接写"已感染:是"——那是 spoiler 也是上帝视角。要让玩家自己拼出来。

### 7.2 大魔潮临近的氛围反馈

游戏内时间一天天推进,大魔潮日益临近。UI / 屏幕氛围能不能有渐变?

例如:
- 屏幕色温随天数推进,逐渐变冷
- 场景里某些植物(暖谷农场的"故乡小树")颜色一天天异常
- 木板时钟的边缘随天数推进有极微妙的裂纹
- 雨/雾出现频率上升

**关键约束**:不能太明显——玩家要"感觉哪里不对"而不是"明确看到警示"。
