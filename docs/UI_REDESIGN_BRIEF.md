## 现有 UI 的 5 个核心面板(参考它们的位置 + 信息内容)

### 1. TimePanel(左上 10,10 - 290,90)
- 显示游戏时间(`Day 3, 15:52`)+ 连接状态(绿色 ● 已连接 / 红色 ● 未连接)
- 当前样式:`Color(0.06, 0.08, 0.12, 0.72)` 半透明黑底,无装饰
- **改进方向**:加暮谷镇风格装饰边框(老松树木纹?),时间显示考虑加"昼/晨/午/暮/夜"图标

### 2. ReflectionPanel(左上 TimePanel 下方,10,100 - 290,145)
- 显示反思状态:平时紫色"🌒 反思: N 条 / 最近 Day X (¥0.X)";反思中变橙色
- **改进方向**:玩家应能点开看反思详情(目前只有计数,内容在 MemoryPanel 里要点 agent 才能看)

### 3. NavLabel(顶部居中 310,18 - 990,58)
- 一行长文字:`[当前] 老松广场  切换:[1]老松 [2]北霜 [3]暖谷 [4]寂塔  [R] 刷新`
- **改进方向**:改成 4 个标签/按钮,当前 location 高亮(类似 RTS 小地图风格)

### 4. Inspector(右上 1000,10 - 1270,370)
- 标题:"「老松广场」9 人在此"
- 列表:每行一个 agent 按钮,显示 `名字 · current_action 摘要`
- 点击 agent → 浮出 MemoryPanel
- 当前问题:**9 人 ScrollContainer 经常撞位 / 文字溢出**

### 5. MemoryPanel(右下 1000,380 - 1270,710,默认隐藏)
- 点 Inspector agent 后浮出
- 反思紫色加粗在最前面,然后观察(👁)和计划(📋)
- 当前问题:**单一 RichTextLabel 列表,缺乏视觉层级**

### 6. PausePanel(左下 10,630 - 290,710)
- 暂停按钮:绿色 "▶ 开始(暂停中)" / 橙色 "⏸ 暂停(运行中)"
- 旁边小字"成本 ¥/min"(未实现,占位)

### 7. LoadingOverlay(全屏,默认显示直到 warmup 完成)
- 黑色半透明 + 居中文字 "⏳ 暮谷镇 · 加载中" + 进度
- **改进方向**:加暮谷镇视觉元素(歪脖子松树剪影、霜髓矿光点、寂塔轮廓),不要纯黑

## 玩家操作

- **数字键 1/2/3/4** 切场所(R 是刷新,跟反思快捷键冲突,需要重做)
- **点 Inspector 里 agent 按钮** 看 memory
- **点 ▶/⏸** 暂停/恢复 sim
- **Ctrl+C** 关 backend(进程层面)

未来要加(Block K):**玩家扮演某 agent 说话** / **注入紧急事件**(比如"大魔潮即将爆发!")。

## 设计目标(优先级排序)

1. **统一视觉语言** —— 所有 UI panel 用同一套像素风装饰边框 + 字体 + 主色
2. **降低信息密度焦虑** —— Inspector 9 人列表不再撞位;反思条目用心象笔记本式呈现而非纯文字
3. **强化暮谷镇氛围** —— LoadingOverlay 加歪脖子松树剪影;TimePanel 加昼夜图标;反思 UI 加梦境碎片元素
4. **改善 agent 视觉辨识** —— 名牌 / 气泡 / 思考状态可区分,不再撞位
5. **可选:整体 TileMap 化** —— Block J,把单图背景拆成可走可碰撞的瓦片地图(工作量 1.5-2 天)

## 风格参考

**强参考**:
- **Stardew Valley** — UI 装饰风格(木质边框、暖色调)、对话气泡、信息层级
- **To the Moon** — 黄昏 / 黄绿 主色 + 像素风叙事节奏 + 心象元素
- **Disco Elysium** — 信息密度 + 反思 UI(对话选项 + 心象注释)

**弱参考**:
- **Hades** — UI hover / 提示弹窗
- **Inscryption** — 笔记本 / 卡牌式心象展示

**禁止**:
- 过亮、卡通可爱风格(违背循环 horror 主题)
- 商业 ARPG 满屏数字 / 技能图标(信息密度错配)
- 过度炫技的粒子特效(性能 + 沉浸感)
