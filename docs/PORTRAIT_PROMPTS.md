# 11 个 NPC portrait 中文提示词 (v2)

> **用于 Image 2 / GPT-Image / 国内 AI 生成 NPC 立绘**,目标画风跟艾琳现有 portrait 一致(高质 anime 半身像 / Granblue Fantasy 风)。
> **v2 改动**:**去掉 "pixel art" 关键词**(Image 2 容易把 anime + pixel 混成"写实素描"),改为纯 **anime bust portrait** 风。

---

## 🎨 风格定调:用艾琳作锚点

把 [艾琳 portrait](https://raw.githubusercontent.com/EricJeason/block7-sim/main/godot_client/assets/portraits/agent_04/portrait.png) **上传给 Image 2** 作为风格参考。然后 prompt 写:
> 与上传的艾琳立绘**完全一致的画风**(anime 半身像,温暖暖色 + cel-shaded 上色,大眼,精细头发)。

如果没法上传参考图,用下面的"通用风格 prefix"也行(明确说 Granblue Fantasy 立绘 + JRPG 角色立绘风,Image 2 能识别)。

## ✨ 通用风格 prefix(每张都用这个开头)

```
任务:为 JRPG 游戏《暮谷镇》生成 NPC 半身立绘(bust portrait),
画风对标 Granblue Fantasy / Genshin Impact / 原神 的角色立绘,
**高质 anime 上色风**,cel-shaded 干净色块,大眼,精细头发,
温暖中性调色(不要灰沉、不要 horror 暗调)。

构图:头肩半身像,正面或微侧脸,角色居中,占画面 70%,
干净线稿 + 平涂上色 + 简单高光。

输出:**透明背景**(transparent PNG),无边框,无文字,无 logo,
**非**写实素描,**非**黑白线稿,**非**水彩,**非**油画。
```

## 1. 林秋(agent_01)村医 · 32 岁女 · **治愈者**

**角色描述**:
- 32 岁中国/东亚血统女村医,身高 160cm
- **黑色长直发松松束在脑后**(发尾自然垂落)
- 穿**浅蓝色立领工作服 + 米白色围裙**,围裙上有淡淡的药草印花
- **袖口卷到肘部,有几道药草汁渍**
- 修长手指,**可以双手捧一个小陶瓷药钵**(里面放着草药)
- 眼神**温柔专注**,微微的微笑或平静表情
- 配色:浅蓝 + 米白 + 棕黑发,**暖色调**

**完整 prompt(直接复制)**:
```
[通用 prefix]

角色:32 岁中国女村医林秋。黑色长直发松松束在脑后,发尾自然垂落,
身高 160cm。穿浅蓝色立领工作服,外搭米白色草药印花围裙,袖口卷到肘部,
有几道淡淡的药草汁渍。双手捧一个小陶瓷药钵,里面放着草药。
温柔专注的眼神,微微的微笑。

风格:Granblue Fantasy 角色立绘风,cel-shaded 高质 anime 上色,
```

## 📌 关键改进点(v2 vs v1)

| 项目 | v1(效果差) | v2(改进) |
|---|---|---|
| 风格关键词 | "anime 像素艺术" | "anime bust portrait" + "Granblue Fantasy 立绘风" |
| 调色暗示 | "horror" "悬疑生活流" | "温暖中性" + 明确**移除**"暗调" |
| 引用 | "Granblue + Stardew Valley + horror" 混搭 | 单一引用 "Granblue Fantasy / Genshin / FF14" |
| 上色 | "muted" | "cel-shaded 干净色块" |
| 负面约束 | 笼统 | 明确 "非写实素描,非黑白线稿,非水彩" |
| 结构 | 段落 | 任务 + 角色 + 风格 分块 |

## 📌 使用建议

1. **第一次定调**:用上面"林秋"prompt 生成 5 张,挑最像艾琳画风的那张作锚点
2. **后续 10 张**:**上传林秋成品** + 简单 prompt"和这张图同一画风,但角色换成 XX(粘贴上面的角色描述)"
3. **若 Image 2 不支持图参考**:每次完整 prompt + 加一句"参考你之前生成的林秋立绘"
4. **生成多张筛选**:每个 NPC 3-5 张挑最好
