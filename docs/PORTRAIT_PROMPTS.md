# 11 个 NPC portrait 中文提示词 (v3)

> **基于 Eric 实测反馈**:用"32 岁中国女村医林秋"这种真实身份描述会让 ChatGPT 走"写实素描中草药女医生"路径,完全偏离艾琳画风。
> **v3 核心改动**:模仿 Eric 已经成功的"项目设计文档"prompt 结构,**用 anime archetype 描述符替代真实身份**(比如"黑发草药师少女"而非"中国女村医林秋")。

---

## 🎯 v3 关键策略

| 策略 | 失败的 v2 | 成功的 v3 |
|---|---|---|
| 角色锚点 | "32 岁中国女村医林秋" | "黑发长发的草药师少女(anime 立绘风)" |
| 风格陈述 | 散文式段落 | **项目文档式分章节**(规范 / 角色 / 输出) |
| 画风锚定 | "Granblue Fantasy 风" | **"和艾琳画风完全一致"+ 上传艾琳样图作参考** |
| 身份/职业 | 写"村医" | 写"草药师少女"或不写,纯外貌 + 道具暗示 |
| 角色名 | "林秋" | **不出现中文角色名**(避免文化 association 拉偏方向) |
| 排版 | 中文长句 | 短行 + 项目符号(更像规范) |

## ✨ 通用规范模板(每个 NPC prompt 都用这个外壳)

````markdown
# 角色 portrait 规范

## 项目信息
- 项目:JRPG 游戏《暮谷镇》NPC 对话立绘
- 输出:256×256 PNG **透明背景**
- 用途:对话框头像(bust portrait 半身像)

## 风格规范
- **画风**:anime 立绘风 — 对标 Granblue Fantasy / Genshin Impact / FF14 立绘
- **上色**:cel-shaded 干净色块 + 简单高光
- **必须**:**和已上传的艾琳样图(蓝白连衣裙金发蓝瞳少女)画风完全一致**
- **必须**:大眼睛 + 精细头发线条 + 温暖暖色调
- **不要**:写实素描 / 黑白线稿 / 水彩 / 油画 / 工笔画 / 水墨
- **不要**:灰沉暗调 / horror 风 / 阴森压抑

## 构图
- 头肩半身像,正面或微侧脸
- 角色占画面 70%,居中
- 干净线稿 + 平涂上色 + 简单高光

## 本次角色
[角色 archetype 描述,见下面 11 个 NPC]

## 输出要求
请生成一张符合上述规范的 bust portrait。
**透明背景**(no background)。
不要边框,不要文字,不要 logo,不要水印。
````

**🔥 最佳实践:每次生成时,把 [艾琳 portrait](https://raw.githubusercontent.com/EricJeason/block7-sim/main/godot_client/assets/portraits/agent_04/portrait.png) 作为参考图上传给 ChatGPT,然后说"参考这张图的画风"。Image 2 / GPT-4o 支持 image 参考,效果会比纯文字 prompt 稳定得多。**

## 1. 林秋(agent_01)村医 · 治愈者

**角色 archetype**:
- **黑色长直发**的**草药师少女**,30 岁出头,温柔气质
- **黑色眼睛**(或深褐色),温柔专注的眼神,微微的微笑
- 穿**浅蓝色立领工作服 + 米白色草药印花围裙**
- 袖口卷到肘部,有几道淡淡的药草汁渍
- **双手捧一个小陶瓷药钵**,里面是绿色草药
- 配色:浅蓝 + 米白 + 黑发,温暖明亮色调

## 📌 关键使用建议(基于你的实测反馈)

### 🔥 最重要的一条:用艾琳作图参考

ChatGPT (GPT-4o/Image 2) 支持图片参考。每次生成时**先上传艾琳现有 portrait** [agent_04/portrait.png](https://raw.githubusercontent.com/EricJeason/block7-sim/main/godot_client/assets/portraits/agent_04/portrait.png),然后说:
> 参考这张图的画风(anime 立绘风,cel-shaded,大眼,精细头发),
> 但角色换成下面规范里的 [角色 archetype]。

这是你已经验证过 work 的策略(截图 3 那张完美像素 idle 就是这样来的——用项目文档当 reference)。

### 第二重要:把角色名隐藏

prompt 里**不写"林秋"、"千绫"这种中文角色名** — 这些名字让 ChatGPT 联想到中医、武侠等文化原型,走写实路径。

改写为 anime archetype:
- ~~"林秋"~~ → "黑发草药师少女"
- ~~"千绫"~~ → "黑发短马尾女武者"
- ~~"白嬤"~~ → "银发神秘老妇"

### 第三:复用成功的项目文档结构

Eric 你截图 4 给 ChatGPT 看了项目文档(2D 像素游戏角色资源规范),然后说"按文档生成金发蓝瞳美女 idle",ChatGPT 立刻生成对路。这是因为:
1. **文档式结构**让 ChatGPT 把它当"规范化任务"
2. **"金发蓝瞳美女"**是 anime tropes 直接命中

v3 用同样思路:每个 prompt 用 markdown 文档结构 + anime tropes archetype。

### 优先级(F4.4 用得最多)

- 🔴 林秋 / 阿杏 / 千绫 先做
- 🟡 早纪 / 沈砚 / 文姐 / 苏拂
- 🟢 马九 / 田柱 / 小璎 / 白嬤
